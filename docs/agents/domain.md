# Domain docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read ADRs under `docs/adr/` that concern the area being changed.
- If either location does not exist, proceed without requiring it to be created.

Use terminology defined in `CONTEXT.md` in issue titles, plans, tests, and implementation. Surface any conflict with an existing ADR instead of silently overriding it.
