# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues at `RVAILab/whiterabbit-cafe-menu`. Use the `gh` CLI for issue operations.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List issues with `gh issue list`, including labels and bodies when relevant.
- Comment with `gh issue comment <number> --body "..."`.
- Apply or remove labels with `gh issue edit`.
- Close an issue with `gh issue close <number> --comment "..."`.

Run commands from this clone so `gh` infers the repository from its Git remote.

When a skill says to publish to the issue tracker, create a GitHub issue in this repository.
